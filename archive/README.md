# Archive

Historical records are split by ownership. Prefer current files in
`knowledge_base/`, `tasks/`, and `docs/` for implementation decisions unless an
archive is explicitly referenced.

- `frontend/`: GuLiCode renderer/app UI records.
- `runtime-backend/`: GraphRuntime, control-plane, workspace, and adapter records.
- `future-server/`: reserved for future hosted/server-side product work.
